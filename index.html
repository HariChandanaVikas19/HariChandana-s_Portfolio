It enables users to browse and enroll in courses, while administrators can efficiently manage courses, bootcamps, and users through a secure dashboard. The application features role-based authentication, responsive design, and a clean, intuitive user interface.

Expense Splitter App

Live Demo GitHub

Project Overview

The Expense Splitter App is a responsive React.js application that helps friends, roommates, or groups track and split shared expenses with ease. Users can add expenses, assign shares among group members, and instantly see a running summary of who owes whom — with built-in logic to minimize the number of settlements needed to balance the group.

Key Features

  • Add and manage group members and shared expenses.
  • Assign shares and track individual balances in real time.
  • Smart settlement calculation to minimize the number of payments needed.
  • Clean, intuitive UI for logging expenses and viewing balance summaries.
  • State management using React Hooks (useState, useEffect) and Context API.
  • Fully responsive design for desktop and mobile devices.

Technologies Used

Frontend: HTML5, CSS3, JavaScript, React.js, React Hooks (useState, useEffect), Context API

Type: Frontend-only application (client-side state and calculation logic)
